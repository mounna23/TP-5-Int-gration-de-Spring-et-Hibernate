#  TP : Intégration de Spring et Hibernate

##  Objectifs pédagogiques

Ce TP a pour but de :
- Comprendre les bases de la **gestion des dépendances** avec **Maven**.  
- Configurer **Spring Framework** pour gérer **l’injection de dépendances** et **les transactions**.  
- Intégrer **Hibernate** pour la **gestion des entités persistantes**.  
- Créer une couche **DAO** (Data Access Object) pour effectuer les opérations **CRUD**.  
- Configurer une **base de données MySQL** pour l’interaction avec les entités.
